Exercise 05: First Nmap Localhost Scan

Objective

Perform a basic network scan against the local Kali Linux machine using Nmap.

Tool

Nmap 7.99

Command Executed

    nmap 127.0.0.1

Target

127.0.0.1 (localhost)

Observations

* The target host was identified as online.
* Nmap scanned 1,000 default TCP ports.
* All 1,000 scanned ports were reported closed.
* No open ports were discovered.
* No filtered ports were reported.

Findings

The localhost scan confirmed that the Kali Linux machine was reachable through its loopback interface.

All 1,000 TCP ports examined were closed, indicating that no applications were listening on those scanned ports at the time of the test.

Security Significance

Network scanning helps security analysts identify exposed services and potential entry points.

Unnecessary listening services should be reviewed because they can increase the attack surface of a system.

Learning Outcomes

* Installed and verified Nmap.
* Performed a localhost scan.
* Identified open, closed and filtered port states.
* Interpreted TCP reset responses.
* Learned how to document network reconnaissance results.

Conclusion

The first Nmap scan was completed successfully against the local Kali Linux machine.

No open TCP ports were identified among the 1,000 default ports scanned.
