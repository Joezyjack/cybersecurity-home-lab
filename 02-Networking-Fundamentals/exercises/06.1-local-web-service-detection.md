Exercise 06: Local Web Service Detection Using Nmap

Objective

Understand how a listening service creates an open network port and how Nmap identifies the service.

Laboratory Environment

* Operating System: Kali Linux
* Scanning tool: Nmap 7.99
* Test service: Python HTTP server
* Target: 127.0.0.1
* Test port: 8000

Commands

Start the local HTTP server:

    python3 -m http.server 8000 --bind 127.0.0.1

Inspect the listening socket:

    sudo ss -tulpn | grep 8000

Scan the test port:

    nmap -sV -p 8000 127.0.0.1

Stop the server using Ctrl+C.

Verify the port after stopping the service:

    nmap -p 8000 127.0.0.1

Security Significance

A listening service creates a potential point of network exposure.

Network administrators should identify unnecessary services, restrict access to required services and keep software updated.

Learning Outcomes

* Created a local HTTP service.
* Inspected listening network sockets.
* Identified an open TCP port using Nmap.
* Practised service detection.
* Observed how stopping a service changes port availability.

Conclusion

This experiment demonstrates the relationship between running applications, listening network ports and network reconnaissance.

All testing was performed against the local Kali Linux machine.
